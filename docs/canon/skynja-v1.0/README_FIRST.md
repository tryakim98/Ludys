# SKYNJA REVISED CANON PACKAGE — 2026-09-23

Dette er den konsoliderte ZIP-pakken bestilt etter revisjonsserien i LUDYS/Skynja-prosjektet.

## Innhold

- `SKYNJA_REVISED_CANON_V1_0.md` — 50 reviderte produktprinsipper.
- `RETAINED_LEGACY_RULES.md` — eldre regler som fortsatt er relevante, med ny scope.
- `SUPERSESSION_REGISTER.csv` — maskinlesbar oversikt over hvilke gamle retninger hvert SKP-prinsipp erstatter/reviderer.
- `PRINCIPLE_INDEX.json` — full maskinlesbar representasjon av kanonen.
- `AGENT_BOOTSTRAP.md` — kort inngangsfil for Codex/Hermes/andre agenter.
- `SOURCE_TRACEABILITY.md` — kilder, hashes og avgrensning.
- `LEGACY_SOURCE_EXTRACTS.md` — kuraterte referanseutdrag av gammel kanon; kun reference-only.
- `CHANGELOG.md` — pakkehistorikk.
- `MANIFEST_SHA256.txt` — integritetshasher for alle filer i pakken.

## Viktigste nye retning

Pakken flytter Skynja fra en tidlig, svært defensiv baseline mot et produkt som kan være:
- AI-native,
- langsgående og personlig,
- multimodalt,
- psykologisk kompetent,
- kunnskapsstyrt,
- adaptivt,
- relasjonelt,
- ambisiøst,
- og fortsatt etterprøvbart, reversibelt og menneskelig styrt der konsekvensen krever det.

### Runtime-kunnskapsregelen

Skynjas faglige AI skal basere sine faglige claims på:

> **godkjent Skynja-bibliotek + autoriserte brukerdata + autorisert situasjonskontekst**

Modellens latente treningskunnskap er ikke en faglig autoritet.

### Hovedregel ved konflikt

`SKP-001–SKP-050` vinner over eldre motstridende produktregler **innenfor produkt-/designretningen**.

Dette betyr ikke at pakken automatisk overstyrer:
- lov,
- personvernkrav,
- sikkerhetskrav,
- klinisk kompetanse,
- skoleeiers myndighet,
- faktisk review,
- pilot-/releaseporter.

## Anbefalt bruk

Gi `AGENT_BOOTSTRAP.md` + `SKYNJA_REVISED_CANON_V1_0.md` til nye utviklings-/research-agenter først. Bruk `RETAINED_LEGACY_RULES.md` og `SOURCE_TRACEABILITY.md` som kontroll mot historisk kontekst.

## Viktig anti-resurrection-prinsipp

Gamle dokumenter er fortsatt historiske kilder, men de skal ikke automatisk kunne gjeninnføre forbud som eksplisitt er revidert i denne pakken.
