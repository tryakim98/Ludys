# Rolle- og agentgrenser

Gjeldende produktretning er [Skynja-kanon 1.0](canon/skynja-v1.0/README_FIRST.md). Eldre arbeidsdeling begrenser ikke i seg selv hvilke forslag og reversible kodeendringer agenten kan utarbeide etter brukerens oppdrag.

## Produkteier/chatsporet

Eier produktretning og konsekvensrike beslutninger. Faglig, språklig, juridisk og klinisk review krever relevant menneskelig mandat. SKP-036 erstatter en universell lærerport med konsekvens- og mandatstyring.

## Repositorysporet

Utvikler kode, typer, schema, validatorer, porter, adaptere, tester, builds og autentiske commits innen gjeldende kanon. Kan utarbeide AI-assisterte innholds- og designutkast med ærlig proveniens. Dette er ikke review eller autorisasjon for reell bruk.

## Agentarbeid

- En agentrapport er ikke bevis uten lokal diff, filinnhold og testresultat.
- To agenter skal ikke redigere samme filer samtidig.
- Ingen agent kan påstå cloudressurser, receipts, fysisk to-enhetsproof eller ekstern review uten faktiske artefakter.
- Innholdsendringer skal ha tydelig hensikt, konstrukt og proveniens. Mengde er ikke review; historiske produksjonstak tolkes innen den aktuelle proofen, ikke som evige produktgrenser.
