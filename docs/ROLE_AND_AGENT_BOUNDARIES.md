# Rolle- og agentgrenser

## Produkteier/chatsporet

Eier pedagogisk konstrukt, aktiviteter, stimuli, transferroller, BM/NN-tekst, voksenkort, alder/verdighet, lydmanus og evidenspåstander.

## Repositorysporet

Eier kode, typer, schema, validatorer, porter, adaptere, tester, builds og autentiske commits.

## Agentarbeid

- En agentrapport er ikke bevis uten lokal diff, filinnhold og testresultat.
- To agenter skal ikke redigere samme filer samtidig.
- Ingen agent kan påstå cloudressurser, receipts, fysisk to-enhetsproof eller ekstern review uten faktiske artefakter.
- Kodeagenten skal ikke masseprodusere eller redaksjonelt omskrive pedagogisk innhold uten egen spesifikasjon.
