# Skynja — tomt skjema for praktisk gjennomgang

**Status: IKKE GJENNOMFØRT.** Fylles ut etter faktisk gjennomgang. Ingen avkrysninger eller resultater er forhåndsbekreftet. Bruk fiktive eksempler uten elevopplysninger. Utfylt skjema håndteres i avtalt reviewkanal.

Bruk resultatene **ikke prøvd**, **observert uten funn**, **funn krever retting** eller **ikke relevant med begrunnelse**. Oppgi konkret øvelse, runde-ID, målform og trinn som ble gjennomført. Ikke tolk et klikk eller fullført runde som bevis på leseferdighet.
